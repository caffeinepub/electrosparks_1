# Specification

## Summary
**Goal:** Update the Base Registration description in the Fee Breakdown section of the Register page to display an additional informational line.

**Planned changes:**
- In the Fee Breakdown section, change the Base Registration description from a single line (`₹149 × 1 member`) to two lines: `₹149 × 1 member` followed by `Includes 1 Technical & 1 Non-Technical Event`
- The second line must match the existing description's font style, text color, alignment, and spacing

**User-visible outcome:** Users viewing the Fee Breakdown on the Register page will see the Base Registration description now includes a second line clarifying that the fee covers 1 Technical and 1 Non-Technical Event.

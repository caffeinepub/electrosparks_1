# Specification

## Summary
**Goal:** Change the global website background color from black to royal beige (`#DCCBB5`) across the entire application.

**Planned changes:**
- In `frontend/src/index.css`, replace all black background color values (`#000`, `#000000`, `black`, and dark OKLCH background variables) with `#DCCBB5` on the body/root selector.

**User-visible outcome:** All pages (Home, Technical, Non-Technical, Register, Contact, Admin Dashboard) display a royal beige background instead of black, while all other styles, effects, and functionality remain unchanged.
